# Protos Electrical Website

This project is a polished static landing page designed for Protos Electrical.

## Run locally

From the project root:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deploy

This site is ready to deploy as a static site on:

- GitHub Pages
- Netlify
- Vercel
- any standard static hosting provider

Upload the project folder or connect the repository to your hosting provider.
